Tooling · go-loadtest-swarm

A load test that can fail a build

A number in a README is a claim. This harness turns the claim into an assertion: a YAML scenario decides what “good” means, the run measures it, and the exit code is the answer — so a regression stops a pipeline instead of being read by nobody.

measured: 5,653 requests from 4 clients in 3s · p95 3 ms · 3 failures (0.05%) · exit 0 · and on a server that drops connections, exit 1
4xx is not a failure

A scenario pointing at the wrong path or sending a stale token did not find a bug in the server: it is counted as Rejected, separately, so that a report sends the reader to the right place.

Percentiles from buckets

Keeping every sample is a memory leak at 100k requests/s, and throwing samples away loses the tail. Buckets 1% wide put the p99 within half a percent of the truth, which is the accuracy a build gate can act on.
